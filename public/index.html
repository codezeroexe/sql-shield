One string. Two ways the database reads it.

SQLShield runs the same classic bypass payload through both query constructions against the same database. Bound as a value it can only ever be data. Interpolated into the statement it becomes syntax, and prints back every row it was never allowed to see. The printer's field is 72 columns wide — that width is the entire lesson.

Mitigation skeleton

            in order — each step depends on the last
          

          
    
            
  1. 
              Trust boundary
              Input arrives here. Everything downstream treats it as hostile by default.
            
    2. 
            
  2. 
              Validation
              Required fields and expected shapes, checked before any statement is built.
            
    3. 
            
  3. 
              Parameter binding
              Values travel beside the statement, never inside it. The fix for everything above.
            
    4. 
            
  4. 
              Least privilege
              The database account holds only the permissions the app actually uses.
            
    5. 
            
  5. 
              Result handling
              Return the columns the caller needs, and nothing more.
            
    6. 
            
  6. 
              Testing
              Run attack payloads before every release. This page is that test.
