Mitigation skeleton

  • Trust boundary: user input enters app
  • Validation: required fields + expected format checks
  • Parameter binding: values are passed as data, not SQL
  • Least privilege: DB account should not have extra privileges
  • Testing: attack payloads must be run before deployment
